My Python Learning Journey

Hey there! Welcome to my repository. This is a collection of the Python scripts and small projects I've been building while teaching myself how to code. It tracks my progress from simple calculators to slightly more complex management tools.

📁 What's in this Repository?
I've grouped my scripts based on what they do so it's easier to navigate:

🏦 Apps & Management
Systems Mini ATM Machine.py – A simple terminal ATM simulation. It handles PIN checking, updates account balances dynamically, and uses logic to make sure you can't withdraw more cash than you actually have.
Student Management System.py & Student Gradebook.py – Scripts I made to practice organizing data. They let you log student info, track enrollments, and calculate grade averages.
Contact Book.py / Create Contact Book.py – A couple of basic scripts to save, store, and look up contact information.

🧮 Calculators & Daily Utilities 
Math tool kit.py & Menu Driven Calculator.py – Interactive menu programs that let the user choose different types of arithmetic and mathematical operations.
Simple calculator.py – One of my very first projects! It handles basic math: adding, subtracting, multiplying, and dividing.
Temperature Convertor.py – A quick utility script to convert values back and forth between Celsius and Fahrenheit.

🛠️ Concepts I've Practiced So Far
While working through these projects, I've managed to get comfortable with:
Loops & Conditions: Using while True loops to keep menus running and if-elif-else statements to guide user choices.
Working with Data: Storing and changing user profiles using Python dictionaries and tracking items in lists.
Input Checking: Validating user input so that entering letters where numbers belong won't completely crash the script.
Short Hand Math: Using shorthand math operators like += and -= to cleanly update variables like bank balances
