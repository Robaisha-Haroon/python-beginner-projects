# My First Python Projects

This repository contains some of my first Python projects that I created while learning Python.

## Projects

### 1. Simple Calculator
A basic calculator that takes two numbers from the user and performs:
- Addition
- Subtraction
- Multiplication
- Division

### 2. Temperature Converter
A simple temperature converter that converts:
- Celsius to Fahrenheit
- Fahrenheit to Celsius

### 3. Menu Driven Calculator
A calculator that allows the user to choose an arithmetic operation from a menu:
- Addition
- Subtraction
- Multiplication
- Division

## Skills Practiced

- Variables
- User input
- Arithmetic operators
- Conditional statements
- Loops
- Basic Python functions
